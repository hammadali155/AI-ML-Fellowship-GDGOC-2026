# Week 2: Data Handling & Visualization

## Overview
This week's task focuses on exploring datasets, understanding data types, and mastering visualization libraries. The primary assignment is an Exploratory Data Analysis (EDA) on the Titanic dataset.

## Assignment: Titanic EDA
The assignment involves:
- Loading the Titanic dataset.
- Cleaning the data (handling missing values, dropping redundant columns).
- Visualizing survival patterns based on gender, class, and age.
- Providing 2-3 lines of strategies and insights for each major step.

## Tools & Libraries Used
- **Python**: Core programming language.
- **Pandas**: Data manipulation and analysis.
- **NumPy**: Numerical computing.
- **Matplotlib**: Basic plotting and visualization.
- **Seaborn**: Advanced statistical data visualization.

## How to Run the Notebook
1. Open [Google Colab](https://colab.research.google.com/).
2. Click on **File > Upload notebook**.
3. Select `titanic_dataset_analysis.ipynb` from the `Week-2-Data-Handling-&-Visualisation` folder.
4. Run the cells sequentially to see the analysis and visualizations.

## Dataset
The dataset is loaded directly using Seaborn's built-in `load_dataset('titanic')` function, which is a common version of the Titanic dataset available for practice.
